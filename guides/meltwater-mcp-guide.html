Meltwater MCP in 60 seconds

What it is, what your customer can ask, and where it fits — before you deploy it.

The one-liner: Meltwater MCP brings your customer's Meltwater intelligence into the AI assistants their team already uses — Claude and ChatGPT.1 They ask a question in plain language and get a cited answer grounded in their own Meltwater data, without logging into the platform or building an integration. As of the July 8, 2026 general availability release, it can also take action — creating and editing searches, drafting outreach — not just answer.6

MCP (Model Context Protocol) is the open standard that makes the connection work. Meltwater has hosted MCP natively since 2025; this is the commercially available, in-assistant version. It surfaces a set of capabilities that map to the products in the customer's plan:1

📝

Ask & Brief

A cited overview or answer on a brand, topic, or event — a structured brief in minutes.

📊

Coverage Analysis

Explore Meltwater metrics conversationally: volume, sentiment, trends, share of voice.

🔍

Manage Searches

Reference asset lists and saved Explore searches — and, with the right permissions, create and edit them.

👥

Profiles & Influencers

People and creator intelligence — who's driving the conversation and whether they fit.

📰

Media Relations

Journalist and outlet intelligence — who's covering a topic and what angle lands.

✨

AI Visibility

How the brand shows up in AI-generated answers (for customers with the add-on).

Why customers trust the output: analytics match the numbers in Explore — not a relevance-weighted sample like Mira Studio.4 When there's no Meltwater data for a question, it returns nothing and shows the query it ran rather than inventing an answer, and it enforces each user's own Meltwater permissions.4
Scope of this guide: this covers the no-code, in-assistant connectors for Claude and ChatGPT — the path your PR, comms, and marketing customers use. It is not the developer / custom-agent path (API token, custom connection URLs, other assistants); that's covered briefly under Troubleshooting & limits.

1

Get Meltwater ready

Owner: Implementation Manager

Your pre-flight check before you involve the customer. Run through this first — deploying into an account without the right entitlements or any saved searches is the fastest way to a flat demo.

  • MCP is on the subscription. An active Meltwater plan that includes a Meltwater MCP package. Access to Meltwater on its own does not automatically include MCP.1
  • A base Explore package is in place. Explore is a hard prerequisite for Meltwater MCP — no Explore, no MCP. Add-on tools follow the customer's entitlements (see the add-on note below for current readiness).4
  • Supported assistant, enterprise tier. Claude Enterprise or Team, or ChatGPT Enterprise or Business. Personal Pro / Plus accounts are much less likely to clear org approval — connectors and plugins are managed at the org level, and a personal account needs the heavier custom-connector setup rather than the native Enterprise connector. Not a hard technical block, just a steep uphill climb.23
  • Sign-in method confirmed. Users sign in with their real Meltwater identity via SSO. They never enter credentials into the assistant.4
  • Add-on entitlements checked. GenAI Lens and Klear tools are still being brought to production-ready status for MCP by Engineering — check current availability before promising them. Media Relations tooling for MCP hasn't started vetting and has no ETA; don't set this expectation with a customer today.4
  • At least one good saved Explore search. Not strictly required — live questions return results without one — but saved searches sharpen results and make citations render predictably. Set one up before you demo.4
Grant each user access inside Meltwater. Even after IT enables the connector, a Meltwater account admin still has to switch it on per user. This is the step most often missed — the "access_denied / no seat" errors almost always land here.2
A

Sign in to Meltwater as an account admin

Use an account with admin access to reach user management.

B

Go to Account → Users

Open User management from the right-hand navigation, then find the user (search or scroll) and open them to edit.

C

Assign the connector seat, then save

Assign the Claude Connector seat or the ChatGPT Plugin seat (whichever the user needs), and save. Removing the seat later revokes that user's access. Repeat for each user.23

2

Enable at the org level

Owner: Champion + IT admin

This is the single org-level switch that turns Meltwater on inside the assistant. It's done once, by whoever owns Claude or ChatGPT for the organization. Your day-to-day champion usually isn't that person, so expect to arm them with what their IT / assistant admin needs.1

  • Who does it: a Claude Owner / Primary Owner, or a ChatGPT Workspace Owner / Admin — enabling it for everyone in the org.23
  • What they do: turn on the Meltwater connector (Claude) or the Meltwater plugin (ChatGPT) at the organization level, following Meltwater's IT admin guide.
  • Then it hands off: once enabled at the org level and access is granted per user (Step 1), each end user can connect their own account (Step 3).
The IT admin steps are Meltwater-provided — point the admin to the one that matches their assistant: Connect Meltwater in Claude — IT admin steps or Connect Meltwater in ChatGPT — IT admin steps. For the security and compliance questions that come up here, share both the MCP Security & Compliance guide (MCP-specific detail) and the Meltwater Trust Center.

Most champions aren't technical and won't be able to answer IT's questions themselves. Send them this — it gives them everything to forward straight to their IT / assistant admin:

3

Connect + first prompt

Owner: End users

With the org-level switch on and their access granted, each user connects their own account — about two minutes, and no credentials ever go into the assistant.1

◆
Connect in Claude
Enterprise / Team
  1. Open Claude, signed in to the org Enterprise account.
  2. Click Customize.
  3. In the search bar, type Meltwater.
  4. Click Connect on the Meltwater card.
  5. A browser window opens the Meltwater sign-in page — sign in with SSO.
  6. Click Authorize. Meltwater now shows as an active connector.
Verify: new chat → ask "List my saved Meltwater searches." The Meltwater icon appears, then a permission pop-up — choose Allow once or Always allow. Seeing your searches confirms it's live.2
◈
Connect in ChatGPT
Enterprise / Business
  1. Open ChatGPT, signed in with the work account (not personal).
  2. Click Plugins from the sidebar.
  3. Search for Meltwater.
  4. Click Connect.
  5. A browser window opens the Meltwater sign-in page — sign in with SSO.
  6. Click Authorize. The plugin's actions appear (gear icon next to Start chat).
Verify: new chat → @mention Meltwater (or + → More → Meltwater) → ask "List actions" or "List my saved Meltwater searches." A list coming back confirms the connection.3
Naming note — the customer's is just "Meltwater." The steps above and the email below reference the connector/plugin named Meltwater, which is what your customer connects to. When you connect your own Meltwater employee (buddy) account to test or demo, use Meltwater Internal instead — same steps, different entry in the list.

Then get them to a fast "aha"

The connection is live — now land a real, tangible win. No special syntax; they ask the way they'd ask a colleague.1

Start with one tangible prompt. Give them a single result they can feel the value of — a morning overview, clustered and quantified:

"Give me a morning overview of coverage about [company] and flag anything that needs attention. Cluster the results by story and give me some high-level stats about each cluster."

Run it live, read the cited result together, then follow up in the same chat — "drill into that cluster," then "compare it to last week."
A few more to try, once the first lands:
• "List my saved Meltwater searches." (also the verify step — confirms it's live)
• "Compare share of voice between us and our top two competitors this quarter."
• "How has coverage of our product launch trended over the last 30 days?"
For a fuller bank organized by workflow, see Deeper workflows.
Best practice, once they're hooked — add a skill. After a few live wins, set up the Brand DNA skill so the customer's brand context (purpose, positioning, tone, audiences) applies automatically to every answer, and briefs reflect the brand instead of a generic read. It's the natural next step, not the first thing to configure — full setup and the ChatGPT analog are in Skills & extending it.2
Handoff — leave them self-sufficient. Before you close out the session, confirm: the user has connected and verified independently; they've run at least two prompts that matter to their role; a Brand DNA (or custom-GPT) context is in place; they know results follow their own Meltwater permissions and workspace assignments — they see exactly what they'd see in the platform, nothing more; and they know who their admin is for adding more users. Then set the expectation: "Ask it the way you'd ask a colleague, and follow up — each question builds on the last."

Put it to work

Deeper workflows by team

The same prompts work identically in Claude and ChatGPT for core Listening workflows (PR & Comms, Marketing & Insights). Media Relations and Influencer Marketing tools are Claude-only today — ChatGPT doesn't yet expose Klear, Media Relations, or GenAI Lens tools, so demo those two workflows in Claude and describe the experience as representative.5

📣 PR & Comms
"What coverage featured our brand this week?"
Also: what's the coverage on breaking news so far, and where? Is sentiment shifting, and what's driving it? Is an issue starting to spike?
📈 Marketing & Insights
"How are we standing out from the competition?"
Also: what's our share of voice vs the competitors we name? Which themes are our competitive edge? How did the last campaign land against benchmarks?
📰 Media Relations
"Which journalists can amplify our story?"
Also: who's covering this topic? What angle is likely to land? Does the pitch align with their audience?
🌟 Influencer Marketing
"Which influencers are best suited for this campaign?"
Also: who's driving the conversation in our space? What hashtags are trending? Are they the right fit?

Make it stick

Skills & extending it

The MCP connection is the access. A skill is the reusable recipe that tells the assistant how to use it well, every time.

The MCP connection — the access

Gets Meltwater into Claude or ChatGPT as a callable set of tools. Without it, the assistant has no Meltwater data to reach.

+

A Claude Skill — the recipe

A reusable set of instructions and reference material you give Claude once, so it applies that expertise automatically whenever it's relevant.

Two real examples worth showing customers on Claude:

Brand DNA — brand context skill

What it does: captures the brand's identity — purpose, positioning, tone of voice with real writing samples, do's and don'ts, audiences. Once installed, trend scoring, briefs, and content review reflect the brand instead of a generic read on the data.2

When to introduce it: once the customer has had a few wins with live prompts — it's a best-practice upgrade, not first-run setup.

Setup (Claude): Customize → Skills → Add → upload the Brand DNA skill file → fill in the template with the customer's details (Claude can walk them through it section by section). After that, just mentioning the brand in a question ("How did we do this week?") applies it automatically — no special syntax.2

Daily Meltwater Brief — recurring briefing skill

What it does: packages a repeatable morning brief into one instruction. The customer just says "run my daily brief" and gets a consistent, cited rundown — overnight coverage, sentiment shifts, competitor moves, anything starting to spike — in the same format every day, built on their saved searches.

Why it lands: it turns a report someone used to assemble by hand into a 30-second ask, and it's an easy, high-frequency habit that makes Meltwater MCP part of the customer's daily routine.

A Meltwater skills library is on the way. Meltwater plans to publish a library of skills built by its own internal experts, designed to work alongside Meltwater MCP — so Claude brings not just the data but the expertise to interpret it. Flag this as coming, not available yet.1
The ChatGPT equivalent — honest version. ChatGPT has no feature that matches Claude Skills 1:1. The nearest approach is a custom GPT loaded with the same instructions and brand files, or reusable project instructions. It gets you persistent context, but it's set up per workspace/GPT rather than as a portable, invokable skill, and there's no shared library equivalent yet. If a customer's differentiator is skills, that's a genuine point in Claude's favor — say so plainly.
When it doesn't work

Troubleshooting & known limits

The failures below are the ones that actually come up in the field, mapped to the fix. Most are access-sequence issues, not real bugs.2310

"Meltwater doesn't show up in my connector / plugin list."
Almost always the account: confirm they're signed in to the work / enterprise account, not a personal one. If it's still missing, their per-user access probably isn't active yet — the Meltwater admin needs to assign the seat (Step 1C). Have them contact their admin.
"I only see 'Browse', not 'Add' custom connector in Claude settings."
Expected on Enterprise plans — only Org Owners can add custom connectors. For the official Meltwater connector this doesn't matter; the org admin enables it once for everyone. This trips people up when they try to self-add a custom connection instead of using the enabled one.
"ChatGPT throws access_denied / 'no seat for this provider'."
The seat isn't assigned. Check both layers: the ChatGPT plugin is enabled at the workspace level by a Workspace Owner/Admin, and the user has the ChatGPT Plugin seat granted inside Meltwater. Missing either produces this error.
"I get a login error signing in to Meltwater."
Sign-in runs through the organization's SSO — confirm the Meltwater account is active and that the user's SSO is set up. If SSO fails, it's a Meltwater admin / Support issue, not a connector one.
"The response came back empty or errored."
Usually an expired sign-in — reconnect the connector/plugin to re-trigger the sign-in flow. In ChatGPT, if a write action specifically is blocked, the workspace may be set to read-only for Meltwater; that's an admin setting.
"Do users have to sign in every session?"
No — they sign in once and the connection stays live. Re-authentication only happens under normal conditions: their SSO session or security policy requires a fresh sign-in, an admin changes or revokes their access, or they connect a new assistant. It's the same SSO flow each time, so an occasional re-auth is expected, not a fault.4
"Can we connect a different assistant — Perplexity, Copilot, Gemini?"
Any MCP-compatible assistant can connect via a custom connection URL today, where the customer's enterprise environment allows it — this may carry added cost beyond the base entitlement. Dedicated connectors (and Gemini, Microsoft) are on the roadmap but directional, not committed dates. For a customer building their own agent, that's the developer path — point them to the developer portal, where the MCP server (api.meltwater.com/v2/mcp) authenticates with an API token today.78
✕ What to set expectations on — not supported today
  • Raw mention exports. It returns AI-generated, cited responses — not raw article lists. For raw dataset access, use the Meltwater Insights API.4
  • Bulk custom scoring / tagging. It's built for interactive, conversational queries, not high-volume programmatic enrichment. Use the Insights API with automations for that.4
  • Always-on real-time streaming. Request/response by design — the assistant has to invoke a tool. For near-real-time delivery, use Insights API Data Streams.4
  • Full Explore+ custom categories & filter sets. The standard tools reach the regular Explore index; deeper custom-index work (custom categories, filter sets) isn't fully reachable via the MCP yet. Custom fields are visible but you can't extract deeper insights from them today.10
